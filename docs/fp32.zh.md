# Binary32 浮点 lane

**简体中文** · [English](fp32.md)

每次 ready/valid 握手传一个 lane、活动位和写回 tag。输出就绪时每拍可接收一项操作。流水线用六个使能周期完成重编码、加数对齐、24 位有效数乘法、宽加法、规格化和舍入。输出背压冻结算术级、valid 和 tag。屏蔽的 lane 保留原 tag，返回零数据和零标志；写回仍检查活动位。

| 编码 | 操作 | 结果 |
| --- | --- | --- |
| 0 | FMA | a × b + c，单次舍入 |
| 1、2、3 | ADD、SUB、MUL | binary32 |
| 4、5、6 | EQ、LT、LE | 整数 0 或 1 |
| 7、8 | I32、U32 转 F32 | binary32 |
| 9、10 | F32 转 I32、U32 | RNE 整数 |
| 11、12 | F32 转 I32、U32 | RTZ 整数 |

RNE 就近舍入，平局取偶；RTZ 向零。乘积为精确零时符号为输入符号异或。RNE 下异号零相加、精确抵消产生 +0，同号零相加保留符号。次正规输入和结果支持渐进下溢，舍入后检测微小。按 RNE 溢出时依规则产生带符号无穷。非法浮点结果与算术 NaN 采用规范安静 NaN `0x7fc00000`。

异常位 4 到 0 为 invalid、divide-by-zero、overflow、underflow、inexact。本组操作的除零位恒为零。信号 NaN 在算术和比较中置 invalid。安静 NaN 无序，EQ 对其返回零，LT/LE 对任意 NaN 置 invalid。两种符号零相等。零乘无穷、加法或 FMA 中异号无穷相加均置 invalid。有限、微小且不精确的结果同时置 underflow 和 inexact；溢出置 overflow 和 inexact。浮转整超界时饱和到最近端点并置 invalid，NaN 取正端点；合法小数若舍入改变值则置 inexact。

算术实现固定 Berkeley HardFloat 提交 `c1105e6ac6a0dd90fc80893efc4830ab609005d3`；乘法前后与舍入接口之间可插寄存器。源码及 BSD 许可证保存在 [third_party/hardfloat](../third_party/hardfloat)。[上游](https://github.com/ucb-bar/berkeley-hardfloat)

`bash scripts/test_fp.sh` 构建 SoftFloat 3e（RISCV 特化）和 TestFloat 3e，具体版本固定在脚本中，许可证均为 BSD 类。独立参考生成操作数、结果及标志，种子为 31703 + 操作编码。C++ 测试交错发送各操作，核对写回 tag、背压期间载荷稳定及屏蔽 lane。定向用例含精确结果为 `0xa8800000` 的融合抵消以及两种整数舍入模式。[SoftFloat](https://www.jhauser.us/arithmetic/SoftFloat.html) · [TestFloat](https://www.jhauser.us/arithmetic/TestFloat.html)
