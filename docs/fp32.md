# Binary32 lane

One ready/valid transfer carries one lane, its active bit and its writeback tag.
The lane accepts one operation per cycle with output ready. Its six enabled
cycles cover input recoding, addend alignment, 24-bit significand multiplication,
wide addition, normalization and rounding. An output stall freezes all tags,
valid bits and arithmetic stages. An inactive transfer returns zero data and
zero flags with its original tag. The writeback logic must honor its active bit.

| Encoding | Operation | Result |
| --- | --- | --- |
| 0 | FMA | Binary32 fused `a*b+c` |
| 1, 2, 3 | ADD, SUB, MUL | Binary32 |
| 4, 5, 6 | EQ, LT, LE | Integer 0 or 1 |
| 7, 8 | I32 to F32, U32 to F32 | Binary32 |
| 9, 10 | F32 to I32, F32 to U32 | RNE integer |
| 11, 12 | F32 to I32, F32 to U32 | RTZ integer |

RNE rounds to nearest with ties to even. FMA rounds once after the addition.
The sign of an exact multiply zero is the XOR of operand signs. Addition of
opposite signed zeros and exact cancellation produce +0 in RNE. Equal signed
zeros add to that zero. Subnormal inputs and results retain gradual underflow.
Tininess is detected after rounding. Overflow rounds to signed infinity when
required by RNE. Invalid floating results and arithmetic NaNs use canonical
quiet NaN 0x7fc00000.

Flags from bit 4 through bit 0 are invalid, divide-by-zero, overflow, underflow,
inexact. Divide-by-zero is zero for these encodings. Signaling NaNs raise invalid
in arithmetic and comparisons. Quiet NaNs compare unordered. EQ returns zero
quietly for a quiet NaN, LT and LE raise invalid for any NaN. Both signs of zero
compare equal. Infinity multiplied by zero and opposite infinite terms in
addition/FMA raise invalid. Finite inexact tiny results raise underflow and
inexact. Overflow raises overflow and inexact.

Float-to-integer rounds according to its opcode. Unrepresentable results raise
invalid and saturate to the nearest endpoint. NaN returns the positive endpoint.
Valid fractional conversions raise inexact when rounding changes the value.

The Chisel implementation uses Berkeley HardFloat commit
`c1105e6ac6a0dd90fc80893efc4830ab609005d3`. The selected upstream sources
and BSD license are preserved in `third_party/hardfloat`. They compile unchanged
with the Morganite Chisel plugin. The split pre/post-multiply and rounding
interfaces allow registers on both sides of the FPGA multiply. [HardFloat](https://github.com/ucb-bar/berkeley-hardfloat)

`bash scripts/test_fp.sh` builds Berkeley SoftFloat Release 3e with the RISCV
specialization and Berkeley TestFloat Release 3e. The exact revisions are pinned
in the script. Both dependencies use BSD-style licenses. The TestFloat oracle
generates operand, result and flag words independently of the RTL. Seeds start
at 31703 plus the operation encoding. The C++ bench interleaves all encodings,
matches writeback tags, checks stalled payloads and repeats selected inputs with
the lane masked. Directed cases include a fused cancellation with exact result
`0xa8800000` and both integer rounding modes. [SoftFloat](https://www.jhauser.us/arithmetic/SoftFloat.html) · [TestFloat](https://www.jhauser.us/arithmetic/TestFloat.html)
